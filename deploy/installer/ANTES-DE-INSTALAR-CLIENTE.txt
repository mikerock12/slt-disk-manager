SLT DISK MANAGER — CLIENTE WINDOWS (BETA DE LABORATÓRIO)

Instale este pacote nos computadores atendidos. Com o Windows ligado ele faz inventário,
SMART e cópia de arquivos. Para clonar, formatar ou instalar sistema, o próprio cliente
reinicia o computador em MODO SLT, sem pendrive (computadores UEFI com Secure Boot
desativado; nos demais use o pendrive SLT Rescue ou o boot pela rede).

COMO CONECTAR
Não é preciso digitar endereço nem pin. Abra o atalho "SLT Disk Manager - Cliente":
ele procura o servidor na rede e mostra um CÓDIGO DE 8 DÍGITOS. No painel do servidor,
digite esse código. O código garante que este cliente fala com o servidor certo.
Se a rede bloquear a busca automática, informe só o endereço do servidor
(por exemplo https://192.168.1.10:7443).

O QUE ACOMPANHA (nada é baixado da internet durante a instalação)
- Cliente com runtime .NET 10 e runtime C++ embutidos; o Windows 10/11 já fornece o UCRT,
  conferido antes de instalar.
- smartmontools/smartctl 7.5 (GPL-2), usado no diagnóstico SMART somente leitura.
As licenças ficam em client\tools e docs\12-licensing-third-party.md.

SERVIÇO DO WINDOWS (opcional, com seu aviso)
Na próxima etapa você pode marcar a instalação do cliente como serviço do Windows: ele
fica sempre conectado e o servidor pode pedir o reinício em modo SLT. O passo pede
permissão de administrador (UAC) e mostra o código de 8 dígitos. Sem marcar, nada muda em
serviços, firewall, boot ou discos; use o atalho "SLT Disk Manager - Cliente".
Se o serviço já existe, deixe marcada a tarefa de atualização: a conexão é preservada.

Com o Windows em uso, o cliente não grava discos: só lê inventário/SMART e arquivos das
pastas autorizadas. O reinício em modo SLT grava apenas um carregador temporário na
partição EFI, removido quando o Windows volta. Leia QUICKSTART.md antes de operar.
Binários ainda não têm assinatura digital do proprietário; confira origem e SHA256.
